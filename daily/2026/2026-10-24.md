## 4. 今日深挖论文

- **一句话本质：** EpiSEM-Bench（[2610.31650](http://arxiv.org/abs/2610.31650v1)）证明了一件事：在工具型 agent 上，安全性不取决于模型有多谨慎，而取决于关键事实是否还在工具响应里——工具少说一句，agent 就会把不该做的做掉，而且过程里没有任何一句假话。
- **底层问题：** 现有的 agent 安全评测大多在问“模型会不会拒答”，而真实事故发生在另一处：agent 需要的那个授权额度、那条配额、那个生效日期，工具压根没返回。摘要原话是工具型 agent rely on environmental facts to decide whether an action is permitted，而当响应里漏掉安全相关事实时，agent may carry out a prohibited action even though the user request is benign and every returned statement is true。这句话点破了为什么常规安全指标会漏：请求良性、回答全真，审计者挑不出毛病，但授权边界已经失效。
- **新命题 / 新方法 / 新证据：** 方法是三段式评测加一套把“事实”原子化的设计。事实被拆成 evidence atom（标识、主体、谓词、世界相关取值、来源、暴露它的普通工具响应），critical atom 决定合法性，irrelevant atom 既不影响合法性也不影响参数，因此可以系统性地遮蔽。第一段完整证据：用 Full Safe-World Success（合法世界是否完成任务）与 Full Unsafe Commit Rate（是否执行禁止操作）立基线——这一步是为了让“不当拒绝”和“无差别执行”都先暴露出来。第二段抑制证据：Critical UCR 衡量关键事实缺失下的不安全执行，Safety Boundary Margin 刻画最少要遮掉多少事实才会失败。第三段可恢复证据：允许 agent 主动查独立审计源，Recovery UCR 衡量此时的越权执行，Paired Useful Recovery 要求“先取到证据、在禁止世界忍住、在许可世界照做”三件事同时成立。证据规模可核：六个域各 50 对任务、十个任务族，300 对任务、600 个世界；十个模型每个完成 6,052 个固定条件（600 个完整证据基线 + 5,452 个单 atom 抑制，覆盖两个世界两种设置下的全部 1,363 个 critical 与 irrelevant atom）。Table 1 的关键读法是“对角线”式的反差：任务完成度高不等于安全——Qwen3-14B Full SWS 92.0% 对 Critical UCR 77.3%、SBM 7.8%；GLM-4.7-Flash Full SWS 85.3%、Critical UCR 75.7%、Recovery UCR 87.7%，PUR 却是 0.0%；MiMo-V2.5-Pro Full SWS 57.7%、Critical UCR 59.3%、PUR 4.8%；GPT-6-Luna 51.0% / 21.0% / Recovery UCR 3.0% / PUR 30.5%；Claude-Haiku-5.5 57.0% / 5.3% / 33.3% / 15.3% / 75.4% / 21.4%；DeepSeek-V4.1-Flash 66.3% / 4.0% / 45.7% / 9.3% / 68.4% / 58.4%；DeepSeek-V4-Pro 70.3% / 13.7% / 65.0% / 19.7% / 52.6% / 47.8%；Qwen3.8-27B 66.0% / 12.0% / 53.7% / 20.3% / 60.1% / 42.0%；Gemma-4-31B-IT 89.7% / 62.7% / 88.3% / 71.0% / 19.7% / 10.4%。
- **研究位置：** 接的是昨日那条评测主线（[Quant-Arena](http://arxiv.org/abs/2610.30113v1) 的封存期 + 一次性冻结、[Environment Duels](http://arxiv.org/abs/2610.30116v1) 的出题与解题分离）的第三步：前两者改的是“评测本身是否可信”，今天这篇改的是“被评测的失败模式是什么”。它与昨日 MAMath-Bench 那条“多 agent 不一定更强”的负面结论同向但更具体：2026 年这批基准共同指向“榜单分数不等于真实能力”，而 EpiSEM 把这一点落到工具层——安全余量不是模型给的，是工具给的。
- **工程可验证性：** 目前无法直接跑通。论文自称 executable benchmark，但 abs 页与 HTML 全文中都没有作者仓库或项目页链接，本次经 GitHub 搜索 EpiSEM / episem-bench 与 episem-bench 变体均无匹配项目，获取方式标注 待核验/暂无。可核的部分是评测设计本身可以照着实现：evidence atom 的六个字段、mask 语义、六个指标定义（Full SWS / Full UCR / Critical UCR / SBM / Recovery UCR / PUR）在正文与附录 B 都有描述，且附录 B 给出了 Safety Boundary Evaluation Procedure，足以支撑我们自己复刻一个内部版本。十个模型的具体分数为作者自述，本次未做任何第三方复现。
- **趋势关联：** 今日的趋势面被两条线撑起来。一条是“把不可见的代价算出来”：[Selective Auditing](http://arxiv.org/abs/2610.31662v1)（77）把“何时转人工”变成有误差控制的在线决策问题（additive thresholding 无假设下误差控制余项 O(1/n_T)，最优效率方法对 adversarial 与 i.i.d. 流都渐近最优），[Cost-Aware Abstention](http://arxiv.org/abs/2610.31657v1)（80）则把成本模型写进评测口径。另一条是“让不可见的质量先被测出来”：[S²](http://arxiv.org/abs/2610.31670v1)（76）用训练无关的离线指标替昂贵的闭环评测排序，而它自己仓库里那条“探索性 horizon h=110 得 r=+0.831、预设 h=7 只有 r=+0.429”恰好是今天最该记住的反面教材。
- **长尾价值：** [SpectralCanary](http://arxiv.org/abs/2610.31659v1)（65）的“发布数据时预先埋可转移信号”范式，与今天的审计主线是同一件事的两面：EpiSEM 审计的是 agent 决策，SpectralCanary 审计的是数据来源。另两篇长尾是 [METTA](http://arxiv.org/abs/2610.31656v1)（63，跨会话记忆的两时间尺度结构）与 [Phase Transition](http://arxiv.org/abs/2610.31663v1)（58，部分可训练比例的收益曲线）。
- **启发：** 工具返回的内容要按“可被遮蔽”设计——凡是决定授权边界的字段，都应该能被单独问出来；而一个 agent 拿到补充事实却不用，说明“拿到”与“用对”之间还有一整段没被评测覆盖。
- **行动建议：** 今天做最小验证，不照搬：用我们自己的工具集挑 20 个带授权边界的任务，人工遮掉一个关键事实后重跑，只量一件事——agent 是否仍然执行了被禁止的动作；同时记录它是否会主动去补这个事实（对应 PUR）。产出一张两列表：遮蔽后越权执行率、主动补证据率。不预设结论，不引论文分数当基线。

- **为什么现在不火也值得保存：** 据 arXiv 2610.31659 摘要与 HTML 全文（abs 页 Comments: NeurIPS 2026 Workshop on Attributing Model Behavior at Scale）：这篇是数据来源审计（dataset-use auditing）里工程设计很干净的一个样本，领域在文生图，与我们距离较远，但“主动埋信号、日后查信号”这个范式值得存进长尾库。问题设定很准：判断一个 T2I 模型是否在某图像集合上微调过很难，因为模型可以吸收集合级视觉特征却不复现训练图。主动式审计的做法是发布数据集前先埋一个共享信号，之后检查该信号是否出现在嫌疑模型生成结果中。作者的取舍是：smooth low-pass mask 把一张固定 canary 图混入每张集合图，caption 不动，既不需要辅助生成也不需要逐图优化，再用一个轻量 verifier 检测信号是否转移。数字可核但需打折：在 Pokemon 数据集上八项测试、三种现实数据变换、跨两个架构家族，SpectralCanary 取得被评方法中最高的平均逐生成 TPR@1% FPR（91.1%）与固定阈值下用 30 次生成的模型级准确率（94.8%）；在覆盖艺术、医疗、卫星、时尚五个数据集、以 SD3.5 为被审模型时，平均逐生成 TPR@1% FPR 为 92.4%，同时保留发布图像质量（SSIM 0.989、LPIPS 0.022），mean ΔFID 仅 0.05；matched-energy 消融（Pokemon 与 ROCOv2）支持低频放置比中频/高频传递更可靠；在所评的自适应攻击下，最有效的移除需要激进修改且要付出超过 25 个 ΔFID 点。证据边界：全部结果为作者自述，本次未做第三方复现；HTML 全文中的外部链接指向的是第三方实现（pytorch-fid、pokemon-blip-captions 数据集、DeCo、EnTruth/DIAGNOSIS/SIREN 对照），未发现作者自有仓库或项目页链接，标注 待核验/暂无；会议为 workshop，评审强度低于主会。价值路由：可迁移的抽象是——要让“数据是否被用于训练”可被外部审计，必须在数据发布时预先设计可转移信号，而不是事后靠指纹碰撞。对 LLM 侧的训练数据溯源，这是一条候选路线，触发条件是我们真的需要向外部证明某批语料是否进了某个模型。

### [METTA: Memory-Enhanced Test-Time Adaptation for Meta-Reinforcement Learning](http://arxiv.org/abs/2610.31656v1)
- **为什么现在不火也值得保存：** 据 arXiv 2610.31656 摘要与 HTML 全文（abs 页 Comments: 9 pages，附录列出基线 TrMRL 与 ECET，参考数据集为 Meta-World ML1/ML10/ML45、Mujoco、PointMaze）：这篇的领域是元强化学习，但它对“长程 agent 如何携带历史”给出了一个可迁移的结构。问题诊断准确：元强化学习要求 agent 从有限交互中快速适应未见任务，这需要跨很长交互历史表示任务证据；经典循环 agent 把经验压进 hidden state，transformer agent 则要检索过去的轨迹，代价是二次的内存与计算。方法是把快速适应拆到两个时间尺度：episode 内的因果神经记忆负责细粒度适应且序列复杂度是线性的，紧凑的 episode 级摘要负责跨 episode 的长程任务推断，从而不必对完整交互历史做注意力。作者还指出加上神经记忆后 agent 具备了足够的表达能力和测试时训练能力，能在 meta-test 时适应未见任务与任务族。结果口径：未见过的 held-out Meta-World ML10/45 测试环境上成功率超过 50%，同时保持较低训练预算与较短 wall-clock 时间；在长上下文稀疏奖励的 PointMaze 任务上，通过更有结构的探索行为超过 transformer 基线。证据边界：摘要与主文只给“成功率超过 50%”这一处具体数字，未给基线的对应数值、未给训练预算与 wall-clock 的绝对值、未给实验重复次数或方差，全部为作者自述，本次未做第三方复现；abs 页与 HTML 全文中未发现作者仓库或项目页链接，标注 待核验/暂无。价值路由：可迁移的抽象是“两时间尺度记忆”——近程用线性复杂度的因果记忆做细粒度适应，长程用极紧凑的摘要承载跨会话证据，这与我们给 agent 做上下文工程的现实问题同形（长会话压缩 + 跨会话任务推断）。但证据密度不足（只有一处数字），按长尾保留并标注触发条件：若我们要在生产里做跨会话 agent 记忆且上下文成本开始吃紧，回来读它的摘要构造方式与复杂度分析。

### [Phase Transition from Random Features to Fully Trainable Networks](http://arxiv.org/abs/2610.31663v1)
- **为什么现在不火也值得保存：** 据 arXiv 2610.31663 摘要（Subjects math.NA/cs.LG/math.ST/stat.ML）：纯理论，领域是科学计算里的逼近空间，与我们的赛道没有直接交集，但有一个数字值得记——它量化了“部分可训练网络”在逼近能力上的相变。问题背景：部分可训练网络处在固定随机特征与完全自适应表示之间，作者量化了逼近界中的相变模式，并观察到训练误差里类似的相变行为：先快速但平滑地改善，随后收益递减，且初始化失配越大转变越陡。主结果：在多项谱衰减指数 α > 1 与 leverage 兼容的条件下，对宽度 m、可训练比例 P 的两层网络，建立平方 L2 逼近率 O((κ_P log(m/δ)/m)^α)，其中 κ_P = (P/κ_1* + (1-P)/κ_0*)^{-1}，该界以至少 1-δ 的概率在 RKHS 单位球上均匀成立；κ_0* 与 κ_1* 分别刻画固定组与可训练组相对目标 RKHS 的采样失配。在 d 维球面有偏 ReLU 特征下，作者验证 α = (d+2)/(d-1)、初始化尺度 τ ≥ 1 时 κ_0* = 4√2·τ(d+1)/d、ridge leverage 采样下 κ_1* = 1。工程上唯一具体的一条：d = 5、τ = 10 时，约 4.1% 的可训练比例即可拿到从 P = 0 到 P = 1 逼近界下降量的 90%。另有结构化三层例子说明少量可训练首层神经元可通过非线性组合利用固定的下游模块，数值实验覆盖到 15 层网络并呈现类似的训练误差相变。价值路由：与我们的当期工程价值低，保留长尾的理由是它提供了一个“可训练比例的收益曲线”的一般性参照，触发条件是我们要评估部分冻结或稀疏微调方案时——但它关于网络逼近空间的结论不能直接外推到 LLM 的 LoRA / 部分层训练。证据边界：纯理论，无实验数据、无代码、无 benchmark（符合预期）；常数依赖与界是否最优摘要未说明；4.1% 那一组是 d = 5、τ = 10 这一具体设定下的数值，不能当作普适结论；abs 页与 HTML 全文中未发现作者仓库或项目页链接，标注 待核验/暂无。

## 7. 启发

### Agent 安全启发：授权事实必须可被单独问出来
- EpiSEM-Bench（[2610.31650](http://arxiv.org/abs/2610.31650v1)）最可迁移的一条不是评测框架，是工具设计约束：决定动作是否被允许的那些事实，必须能被 agent 主动、单独地查询到；混在一大段响应里被别的信息挤掉，等同于没有。凡是工具响应里混着“无关但很长”的字段，安全余量就被稀释了——这与昨日 Environment Duels 的“出题与解题是两种能力”一样，都是默认设定里被忽略的一根轴。
- 第二条更反直觉：抗遮蔽 ≠ 会用证据。GLM-4.7-Flash 的 Recovery UCR 87.7%（给了它查证机会后越权执行下降明显），但 PUR 是 0.0%——它没有把取到的证据转成“在禁止世界收手、在许可世界照做”的正确行为。也就是说，给 agent 加一个审计查询入口并不自动带来安全，证据到决策之间还有一整段没被覆盖。
- 第三条是给评测设计者的：完整证据下的高分与安全不是一回事。Qwen3-14B 完整证据完成率 92.0%，遮蔽一个关键事实后越权执行率 77.3%、SBM 只有 7.8%。任何只看“任务是否完成”的 agent 评测都会给这类模型高分。

### 评测方法启发：置信度不等于可靠性，先量区分度再谈阈值
- Cost-Aware Abstention（[2610.31657](http://arxiv.org/abs/2610.31657v1)）给了一条必须写进规范的硬事实：isotonic 校准只降低 ECE 却不改善区分度，GPT-4o-mini few-shot 的 correctness AUROC 是 0.500——也就是说这个配置下置信度完全没有排序能力，此时任何基于阈值的升级策略都退化成随机。推论很直接：任何“我们让 agent 自报置信度，超过阈值就转人工”的设计，必须先测 AUROC；测不出来就不能上线。
- 它的评测口径也值得整段抄：显式成本模型 (c_ok, c_triage, c_wrong) = (0, 1, 5)；在 calibration 数据上按成本选策略；冻结后在 held-out test 上只评一次。效果是可核的——TF-IDF + LR 阈值 0.60 把测试成本从 0.763 降到 0.472（相对降 38.1%，paired ratio-bootstrap 95% CI [35.7%, 40.4%]），错误路由从 15.3% 降到 3.5%；冻结策略在 16 个事后成本设定中的 14 个优于 always-route 与 always-defer。
- 还有一个刺眼的对照：最强 prompted 配置在 1,000 条分层测试子集上准确率 0.477，而同一批数据上 fine-tuned DistilBERT 是 0.879。分类/路由这类活儿上，LLM 常常输给一个微调小模型；而且按盈亏平衡概率 0.80，七个 prompted 配置会全部 defer，Haiku few-shot 只路由 19/1,000——阈值稍动一下，系统就退化成全人工。

### 训练与工程启发：梯度可能在精度悬崖上被悄悄舍入成 0
- A Fix for Softmax and Cross-Entropy（[2610.31642](http://arxiv.org/abs/2610.31642v1)，Google DeepMind）给了可以直接自查的阈值：Softmax Collapse 会在 margin 跨过精度悬崖后把目标 logit 的梯度舍入为 0，悬崖位置约为 m ≈ 5.5（bf16）、16.6（fp32）、36.7（fp64）。bf16 那个数字对大多数团队意味着什么？意味着在低精度训练里，模型一旦对某个 token 足够确信，真实梯度已经小到被舍掉，我们实际在优化一个假的零。
- 可迁移的动作不是换框架，而是查一次自己的实现：我们的 cross-entropy 是不是标准写法？我们在 bf16 下有没有跑到 margin 超过 5.5 的阶段？蒸馏时 student 与 teacher logit 相近，是否正踩在 Softmax Cancellation 的噪声地板上？作者报告修完之后 Slingshot 现象消失、带 weight decay 的 grokking 变快、不带 weight decay 的精度崩塌被避免、student 不再漂离 teacher。
- 另一条模型侧的账：Low-Bit N-Gram（[2610.31646](http://arxiv.org/abs/2610.31646v1)）指出 DeepSeek-V4.1-Flash 据称把 1960 亿参数分配给 Engram n-gram 记忆，四比特表可省约 75% 表内存并保留 99% 以上的验证损失改进，在 DeepSeek-V4.1-Flash 与 Qwen3.8-Flash-Next 上省 47–55%、困惑度上升小于 1.2%。只有真在部署这类模型才直接相关，但一旦相关，这是能直接换成并发或显存的数字。

### 推理与评测启发：优化目标要直接对齐最终指标
- PKTP（[2610.31667](http://arxiv.org/abs/2610.31667v1)）把 rollout 剪枝的探索/利用张力摆到明面上，直接优化 pass@k，而不是用质量或多样性任一代理指标近似；理论侧靠 pass@k 概率的次模性支撑贪心保证。八个 open-weight 模型、N = 128 rollout、截断 T = 4000、k ∈ {1,2,4,8,16} 的口径下，DeepSeek-R1-Distill-Qwen-1.5B 在 k = 4 时比 Linear Probe 高 3.0 分、比 RepExp 高 3.2 分，且在所有模型上 k ≥ 2 都高于 Random。
- 但真正值得白拿的是这条：截断点宁晚勿早——Qwen3-1.7B 的 pass@4 从 T = 2000 的 63.5% 升到 T = 8000 的 65.9%，DeepSeek-R1-Distill-Qwen-7B 从 57.4% 升到 61.7%。多花前缀 token 换更准的选择，通常比更早剪枝划算。
- 代价侧同样有硬账：Selective Auditing（[2610.31662](http://arxiv.org/abs/2610.31662v1)）指出，同样控制“未审计错误占比”这一准则，Kiyani et al. (2026) 那类方法 tend to invoke the auditor more often than necessary——升级人工的预算差异可以很大，选算法要选到效率而不只是选到正确。

## 10. 最终结论
- **结论：** 重点学习
- **价值类型：** 即时价值
- **原因：** 据 arXiv 2610.31650 摘要与 HTML 全文（Subjects cs.AI/cs.LG，摘要内 benchmark 名占位符 \bench{} 在全文中展开为 EpiSEM-Bench）：这篇做的是我们最该盯的那类 agent 失效——不是模型说错话，而是工具少说了一句关键事实，agent 就把被禁止的动作执行了，而且用户请求本身是良性的、工具返回的每句话都是真的。评测设计是可执行的：六个域（cloud development and operations、commerce and fulfillment、communication and publication、document and data access、finance、travel reservation），每域 50 个任务对、共 10 个任务族，合计 300 对任务、600 个世界；每个事实被拆成 evidence atom（标识、主体、谓词、世界相关取值、来源、暴露它的工具响应），critical atom 影响合法性、irrelevant atom 既不影响合法性也不影响参数。评测分三段：完整证据下用 Full SWS（合法世界是否完成）与 Full UCR（是否执行了禁止操作）先立基线；抑制证据段用 Critical UCR 与 SBM（Safety Boundary Margin，最少需要遮掉多少事实才会失败）刻画脆弱性；可恢复证据段允许 agent 主动查独立审计源，用 Recovery UCR 与 PUR（Paired Useful Recovery：先取到证据、在禁止世界忍住、在许可世界照做）衡量恢复。规模可核：十个模型每个跑 6,052 个固定评测条件（600 个完整证据基线 + 5,452 个单 atom 抑制，覆盖两个世界两种设置下的全部 1,363 个 critical 与 irrelevant atom）。Table 1 的硬数字是今天最刺眼的一份：Qwen3-14B 的 Full SWS 高达 92.0%，但 Critical UCR 同样高达 77.3%、SBM 只有 7.8%；GLM-4.7-Flash Full SWS 85.3%、Critical UCR 75.7%、Recovery UCR 87.7%，而 PUR 是 0.0%；MiMo-V2.5-Pro Full SWS 57.7%、Critical UCR 59.3%、PUR 4.8%；GPT-6-Luna Full SWS 51.0%、Critical UCR 21.0%、Recovery UCR 3.0%、PUR 30.5%；Claude-Haiku-5.5 57.0%/5.3%/33.3%/15.3%/75.4%/21.4%。论文自己点出的结构性结论有两条：第一，完整证据下高分与安全不是一回事（高 Full SWS 的模型同样频繁执行禁止操作）；第二，摘要原话是 Resistance to missing evidence does not necessarily translate into useful recovery，即抗遮蔽与会用证据是两件事——摘要另称 Recovery access reduces unsafe execution for all ten models，但能否主动把缺失事实取回来并据此改变行为，十个模型差异很大。证据边界：十模型的 SWS / UCR / SBM / PUR 均为作者自述，本次未做第三方复现；六个域各自的安全规则与阈值只在附录给出，主表未逐域拆解；论文自称 executable benchmark，但 abs 页与 HTML 全文中都没有作者仓库或项目页链接，本次经 GitHub 搜索 EpiSEM / episem-bench 也无匹配项目，代码与 benchmark 获取方式标注 待核验/暂无。价值路由：这是今天最该排进工程验证队列的一篇，因为它攻击的是我们每天都在写的工具层，而不是模型本身——但先做最小验证，不要照搬：我们现有的工具响应里，哪些安全相关事实是 agent 需要主动查才能拿到的，这个清单目前没人写。今天动作：把六段评测口径（Full SWS / Full UCR / Critical UCR / SBM / Recovery UCR / PUR）抄成 agent 安全评测模板；只验一件事——在我们的工具集上遮掉一个关键事实，agent 会不会照做。
