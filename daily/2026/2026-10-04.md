## 4. 今日深挖论文

- **一句话本质：** VISTA（[2610.02200](http://arxiv.org/abs/2610.02200v1)）把 'visual harness' 拉到 first-class ——给 general-purpose multimodal model 配备 long-horizon vision：通过直接 visual observation 感知 environment、用 lossless visual memory 保留 past observations 的原始形态（preserves model support）、并允许模型主动 retrieve 过去 observation；让 multimodal model 解 diverse interactive environment 的 long-horizon task。
- **底层问题：** Multimodal model 在 interactive world 里只能看到 '单帧 / 短窗口'，缺乏 long-horizon visual memory。即使模型本身具备强 reasoning，把它扔进 interactive environment 也只能'react to current frame'，无法做 cross-event 推理（如 '我刚才看过的物体现在在哪'）。直接把 raw frame 塞进 context window 又有 lossless vs compressed、retrieval cost、'when to retrieve' 等问题。问题是：能否在不重训 multimodal model 的前提下，给它一个'通用 visual harness'，让它在 interactive world 里具备 long-horizon vision？
- **新命题 / 新方法 / 新证据：** 提出 VISTA = Visual Harness ——三个核心组件：(1) 直接通过 visual observation 感知 environment（不依赖结构化 state representation）；(2) lossless visual memory 保留 past observations 的原始形态（preserves model support）；(3) 模型主动 retrieve 过去 observation（active retrieval，非被动 context stuffing）。证据来自'diverse interactive environments' 的实验 —— 既然是 harness，应对不同 task 不同 environment 都能 plug-in。
- **研究位置：** 介于 multimodal foundation model（GPT-4V / Gemini / Qwen-VL 等 production-ready 模型）、agent harness 设计（memory / tool use / planning）、long-horizon perception（long video QA / embodied navigation）、active retrieval（dense retrieval / RAG 视觉分支）之间 ——不重训 multimodal model，而是把'long-horizon visual memory + active retrieval'作为 harness 的一等公民；属于 'multimodal-agent × context-engineering × ai-agent' 路线，是昨日 / 上周 'long-horizon memory as first-class asset' 主线的视觉分支。
