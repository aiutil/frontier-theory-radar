## 4. 今日深挖论文

- **一句话本质：** 当 agent 替你做实证研究时，它做的不是'分析'，而是一次开放式的**多假设选择**——而你的 p 值完全没有为此付出代价。论文给出的解法不是更小心地分析，而是**把选择过程重放出来并量化它**。
- **底层问题：** 经典推断假定分析是事先指定的，或对'挑了 99 个分析再看最显著的那个'有已知偏倚校正。但 agent 的搜索空间是**隐式**的：它自己决定看哪些变量、跑哪些模型、用什么口径。你甚至不知道它搜了多少个'估计量'，因此传统多重比较校正无从下手。作者把它称为 selective inference 的'超级版'——比人类研究者更宽的搜索空间，但换来了程序化的可重放性。
- **新命题 / 新方法 / 新证据：** 校正的思路是把因果方向倒过来——不问'agent 可能选了什么'，而是**直接测**：agent 完成分析后，把数据重置，在子样本上重放同一个 agent，统计'当某个分析看起来统计显著时，agent 选中它的相对概率'，然后据此修正。关键的设计选择是：修正量**从黑箱 agent 的实际行为里学出来**，而不是假设一个搜索模型。这一点决定了方法在模型迭代后仍然成立。
- **研究位置：** 它是一篇立场 + 方法论文，方法上承接 'post-selection inference' 的传统，但在 agent 这个新主体上重述了问题，并给出了可操作的对照实验。
- **工程可验证性：** 这是今天 15 篇里**唯一一篇我能把声明的产物逐层打开核对的**：作者复现包仓库实测 HTTP 200、2177 个文件（`code/` 十二个模块、`results/numbers/` 十份数值 JSON、`paper/main.tex` 223767 字节、`paper/figs/`、`paper/tabs/`），`run_all.sh` 约 8 分钟在笔记本上重建全部表格与图且**不调用任何语言模型**；README 声明 CC0 1.0 的部分与 CC BY 4.0 的自产数据分别标注了许可。我实测拉取了 `results/numbers/10_self_correction.json`、`02_open_ended.json`、`01_fixed_design.json`、`04_power.json` 四份数值文件，`paper/main.tex` 正文与摘要的 54%–98% 区间逐句对应。
- **长尾价值：** '由 agent 产生的推断'是一个会长期存在的对象，而不是一次性话题。任何'黑箱系统做了开放式选择、然后我们只报告被选中的那一个'的场景——自动文献综述挑出的最佳结论、agent 选出的最佳代码方案、RAG 里被当作唯一依据的那段证据——都是同一个选择性推断问题，而这篇论文给的是可迁移的解法模板。
- **启发：** 与其要求 agent '更严谨地做研究'，不如要求它**把选择过程留痕**。可重放的选择记录（agent 看过什么、排除了什么、在哪一步停止）本身就是最便宜的审计证据；今天同批的 2611.22901 用 anytime 评测把'中间状态'重放、2611.22461 指出'悄悄消解矛盾会让投毒不可见'，都是同一个母题：**让被省略的中间过程重新可观测**。

## 7. 启发

### 系统设计启发

**1. 选择过程必须是一等公民数据，而不是副产品。** 这篇论文最可迁移的工程结论不是统计方法本身，而是一个记录规范：**任何由 agent 做出的开放式选择，都应该把'看过哪些候选、为什么选中这个'记下来**。我们现在的日志大多只记最终答案，于是选择偏倚既不可见也不可量化——论文里 54%–98% 的误拒率之所以能长期存在，正是因为它藏在聚合指标背后。

**2. '重放'是比'审查'更便宜的验证手段。** 审查一份 agent 产出的分析要人读代码；重放只要把输入换成子样本再跑一遍。作者的复现包甚至不调用语言模型就能在 8 分钟内重建全部结果。这意味着**我们大部分 agent 工作流其实具备做统计审计的条件，只是没有把重放入口做出来**。把'同一 agent + 同一提示 + 扰动输入'做成一个一等公民的调试接口，比加十条 prompt 规则都有效。

**3. 黑箱不可怕，可建模的假设才可怕。** 作者的方法刻意不假设 agent 的搜索机制，只估计它在特定条件下的实际选择概率。这个思路可以直接搬到 agent 评测里：我们不需要知道 judge 为什么给这个分，只需要能重跑 judge 并测量它在'看起来合理的答案'上的偏好分布。**凡是需要用假设换确定性的地方，先问能不能用重放换测量。**

**4. 同一母题的三种形态。** 今天这批里，2611.23174 要求'选择可重放'，2611.22901 要求'中间状态可重放'（anytime 评测重放已录制轨迹并用隐藏测试给中间 patch 打分），2611.22461 要求'冲突不要被静默折叠'。三者都在说同一件事：**流水线里被省略的中间过程，是最难被发现的缺陷藏身处。** 我们现有的 agent 平台在这三处都只保留了最终结果。

### 值得存下的反常识点

- **'agent 找到的显著结果'比 'agent 运行失败' 更危险。** 失败会报错，错误结论不会。98% 的误拒率在任何监控面板上看起来都像'模型很强'。
- **预注册是最强的单一防御。** 复现包的 `04_power.json` 显示预注册检验在中等效应下拒绝 78.8%，而重放检验 49.5%——预注册本身就把过度拒绝压下去了，重放是在此之上的精确化。这条对我们要写进方法规范的结论是：**能预注册就不要靠后校正。**
- **'更强的模型'不等于'更少的假阳性'。** 复现包记录 Sonnet 与 Opus 5.5 在零效应下分别 74% 与 54% 显著——更强的模型在这里表现并不单调。**用模型升级解决选择偏倚是错的方向。**

### 今天不要做的三件事

- **不要**把今天任何一篇的'显著提升'数字直接搬进我们的选型结论——除深挖那篇外，其余论文的仓库与数据入口均未核验。
- **不要**因为'多 agent 辩论里保留矛盾'（2611.22461）就去改我们的记忆模块——它自己也报告了写信任门与 router 来源特征**比什么都不做更差**（-0.075 / -0.096 F1），说明这类改动极易踩坑。
- **不要**用更贵的模型去压 agent 的假阳性率——数据显示模型强度与假阳性率不单调。

## 10. 最终结论
- **结论：** 重点学习
- **价值类型：** 即时价值
- **原因：** 提出了'重放式选择校正'——把 agent 自己的选择性行为本身变成可估计量，从而修正 p 值。证据强度在今天这批里最扎实：作者自建复现包 github.com/Davidvandijcke/inference_after_coding_agents_replication 实测可达（HTTP 200，2177 个文件，含 code/、results/numbers/、paper/main.tex），results/numbers/10_self_correction.json 直接写明四个前沿 agent 在零效应数据上报告显著 p 值的比例为 [53.61%, 97.98%]，与摘要中的 '54% 到 98%' 完全吻合；02_open_ended.json 给出 agent 拒绝率 0.9798 vs 重放后 0.0505，即把误拒率拉回名义 5%。main.tex 可下载（223767 字节），复现包 run_all.sh 约 8 分钟跑完且不调用任何语言模型。工程价值在于方法本身就是一段可复制的流程（分析完成后重置 agent、在子样本上重放、估计'看起来显著时它会选中该分析的概率'），可以直接落到我们对 agent 生成结果的统计复核上。长期价值在于它把'agent 时代的推断'变成一个持续有效的对象：校正量是从黑箱 agent 的实际选择中学出来的，而不是假设某个搜索模型。
- **最大不确定性：** 1. **校正依赖选择行为稳定性。** 论文的有效性前提是 'for agents with stable selection behavior'——作者本人把稳定性写成了适用条件，这意味着当 agent 升级、提示改写或工具集变化时，校正量需要重新估计。论文没有给出「行为漂移到何种程度就失效」的量化边界，这是最需要后续跟进的问题。
2. **复现包的数据可用性有保留。** 其 README 明确声明：Card and Krueger (1994) 文件无许可声明，仅在署名的前提下原样分发；Kaufmann, Andre and Kőszegi (2024) 文件在 Dataverse 标为 CC0 1.0，但作者 README 标为 CC BY-NC 4.0（仅限非商用）；ISSP Role of Government 微观数据无法完全公开。因此「完整复现」在数据层面存在硬约束，README 的可用性清单里 'All data are publicly available' 一项是**未勾选**的。
3. **agent 会话本身不可精确复现。** 复现包 README 说明 agent 输出是采样产生的，因此把已录制的 agent 输出作为数据固化下来，`run_all.sh` 从这些录制结果出发；真正跑 agent 的代码在每个模块的 `data_generation/` 目录下。也就是说，**端到端的 agent 行为并未被完全固化**。
4. **强结论的适用范围。** 98% 的误拒率来自模拟的零效应数据与特定提示（'produce a compelling finding'）；在真实研究场景中 agent 搜索空间更复杂，选择行为是否同样稳定，论文未回答。
5. **同期论文的证据等级不一。** 本次 15 篇候选中，只有 2611.23174 的声明产物被逐层打开核对到具体数值文件；2611.22461 与 2611.23202 找到了内容相关但**未出现本论文 arXiv 编号**的仓库（`ziakhan1516/Debat-Agent-NeurIPS-2026`、`CalPolyPomonaCS/Agent-Trust-Infrastructure-ATI-Official`），只能算部分支持，不能当作官方实现；2611.22425（`sungkites/LMMR`）与 2611.22297（`Latte00/FIRE-drive`）仓库实测可达，但同样缺少编号级绑定；2611.22509 声称的数据集 `huggingface.co/datasets/leequeue/MIPR` 在本环境**连接反复超时/被拒**，无法确认其存在与内容。以上一律按待核验处理，未计入今天的结论强度。
