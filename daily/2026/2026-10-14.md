## 4. 今日深挖论文

- **一句话本质：** RSI-Anything（[2610.13912](http://arxiv.org/abs/2610.13912v1)）把 recursive self-improvement（RSI）的'external feedback 昂贵 / world-model predictions 随 policy 演化不可靠'推到 'JEPA-Anything 框架：predictive world models 引导 action selection + learning-data selection + observed feedback 驱动 policy/workflow 改进 + conditional world-model adaptation + component & compatibility checks'——一个 domain-general 的世界模型驱动自改进框架。'world-model-as-self-improvement-curriculum' 把 agent 自我进化从 '依赖 external feedback / 静态 world model' 两态拉到 'predictive world-model drives both action and learning-data selection with component & compatibility checks'，是 2024-2026 'agent RSI / world model / data curation' 路线上极具冲击力的具体范式——把 'self-improve' 从 'static-policy + slow-feedback' 拉到 'world-model-curriculum + fast feedback loop'，符合 aiutil 长期关注的 ai-agent × llm-evaluation 主线。
- **底层问题：** 当前 RSI 范式要么靠 'expensive external feedback（人工标注 / 真实环境 rollout）'，要么靠 'static world model（policy 一变就 drift）'。问题：'world-model-driven action + learning-data selection' 是不是能在不依赖持续 external reward 的前提下，让 agent 既能选 action 又能选 '应该学什么数据'，并用 component & compatibility checks 担保自改进过程不破坏既有能力？——'world model as both policy prior and data prior' 是不是 RSI 真正可行的中间路径？瓶颈：predictive head 是否对未见 task 仍然可迁移、compatibility check 是否能在不重训全模型的前提下检测 capability degradation、learning-data selection 的 bias 怎么量化。
