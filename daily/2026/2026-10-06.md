## 4. 今日深挖论文

- **一句话本质：** LESSER（[2610.03702](http://arxiv.org/abs/2610.03702v1)）把 LLM post-training data selection 的 ranking signal 从 'full-parameter backward pass per sample' 推到 'output-layer gradients' ——用 approximate output-layer gradient 在保留近似 full-gradient 信号的同时把 per-sample 算力压到常数倍，让 large candidate pool 的 gradient-based data selection 变得算力可承受。
- **底层问题：** LLM post-training 的数据选择是 '怎么挑最有用的 sample 进 RLHF / SFT / DPO'。现有 gradient-based selection（influence functions、TracIn、Grad-Diff 等）要对每个 candidate sample 跑一次 full-parameter backward pass 算 gradient，再 rank；候选池一上百万条 sample 时算力直接爆掉。但 'output-layer gradient' 是否能近似 'full-parameter gradient' 的 ranking 信号？这个问题之前没人严格给出过 ——要么觉得可以（但缺乏证据），要么坚持 full pass（但实际不可行）。问题是：能否在常数倍 cost 下用 output-layer gradient 给 LLM post-training data selection 一个可信 ranking signal？
- **新命题 / 新方法 / 新证据：** 提出 LESSER = Post-Training Data Selection with Output-Layer Gradients ——用 output-layer gradients 做 per-sample ranking signal，在保留近似 full-gradient 信号的同时把 per-sample cost 压到常数倍（vs full backward）。证据来自：'approximating full-gradient features at a fraction of the cost' 的对比实验 + 跨 LLM post-training 任务的下游性能验证。
- **研究位置：** 介于 LLM post-training pipeline（RLHF / DPO / SFT）、data curation & selection（influence functions / TracIn / Grad-Diff）、gradient approximation（last-layer / LoRA-back / 随机 projection）、LLM training infrastructure（memory / compute budget）之间 ——不重训 data selection 算法本身，而是把 ranking signal 从 'full backward' 降到 'output-layer gradient'；属于 'inference-serving × llm-evaluation × memory' 路线，与昨日 / 上周 TACO（ternary optimizer state compression）在 '把训练时 memory/compute 维度变成可量化工程对象' 层面同源。
- **工程可验证性：** 暂无开源代码 / benchmark / 项目页链接，需打开 PDF 看 output-layer gradient 形式化（per-sample cost vs full backward 的精确比）、跨 AdamW / LoRA / full-finetune baseline、跨 LLM 规模（百万 → 百亿参数）验证、与 influence-function / TracIn 等近似 ranking baseline 的 rank correlation 对照、跨 RLHF / DPO / SFT 三种 post-training 范式的下游表现。
- **趋势关联：** 'output-layer as governance surface' 是 2024-2026 在 '把 LLM training pipeline 维度变成可量化工程对象' 趋势下的具体落地 ——与 TACO（optimizer state memory compression）、NEPA（next-embedding diffusion condition）、今日 LESSER 共同构成 'LLM training/serving memory & compute as engineering object' 趋势资产。
- **长尾价值：** 即使短期不火，'output-layer gradient as approximate ranking signal' 范式也可沉淀为 LLM data curation 的工程基线，与 aiutil 长期关注的 inference-serving × memory × llm-evaluation 主线在 'data governance surface' 层面同源。
- **启发：** 为团队日后做 'LLM post-training data curation' 提供 'output-layer gradient ranking' 具体范式 —— 把 'full backward pass' 换成 'output-layer gradient constant-cost ranking'，可在 1×A100 级别单卡完成百万 sample 候选池的 data selection。
