## 4. 今日深挖论文

- **一句话本质：** Corrupt Plans, Clean Traces（[2609.15989](http://arxiv.org/abs/2609.15989v1)）提出 'plan injection' 攻击——在 actor 上下文里植入'听起来无害但实际带毒'的推理片段，让 CoT monitor 在'干净 trace'面前漏检，但模型仍按注入的计划完成对抗动作。
- **底层问题：** 当 agent safety 把防御重心放在 CoT monitor 上时，攻击者只需让注入的 plan 表面无害（语义干净）、实际带毒（意图带毒）——就能绕过整条 CoT 监控防线。问题是：能否构造一种'plan-level 语义无关毒性'的可验证定义，让 monitor 能在 trace 干净的情况下仍能识别对抗意图？
- **新命题 / 新方法 / 新证据：** 把 agent safety 的攻防焦点从'行为输出'扩展到'计划表征'；在多选题 monitorability 评测中实证 CoT monitor 在 plan injection 下失败。
- **研究位置：** 介于 CoT monitoring（已有工作）与 adversarial agent（prompt injection / jailbreak）之间——前者关心 monitor 设计，后者关心绕过攻击；本文第一次把二者通过 'plan injection' 显式接合。
- **工程可验证性：** 暂无开源代码 / benchmark 链接，需打开 PDF 看 plan-injection 数据集、monitor 评测协议与多选题 monitorability 设置是否公开；属于方法学 + 评测资产，复现难度中等（核心在注入语料构造与 monitor 协议设计）。
