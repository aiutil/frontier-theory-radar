- **底层问题：** 现有 RL 后训练 MLLM 的幻觉抑制效果不均匀——同一个 RL recipe 在不同 query 类型上'幻觉能压住还是压不住'差异巨大。根因是 correction chain（reward → rollout → group advantage → parameter update）存在两处可观测弱点：(a) 语义熵高的 hard queries 在 rollout 时倾向 unanimous-wrong group，group-relative advantage 坍缩到 0，参数根本不更新；(b) confidence 在 advantage estimation 里被滥用，进一步放大坍缩效应。问题是：能否从'entropy signal × correction chain 弱点'的视角，给出一个可移植的工程治理方案？
- **新命题 / 新方法 / 新证据：** 把幻觉问题显式拆为 rollout 层的 group-relative advantage 坍缩 + optimization 层的 confidence 滥用两个机制点；用熵信号（dual entropy）双侧干预——在 hardest queries 上不让 advantage 坍缩，在 confidence 上不让其被滥用。
