- **一句话本质：** Co-Evolving Acting and Forecasting for Language Agents（[2610.20597](http://arxiv.org/abs/2610.20597v1)）把 language agent RL 的'长 horizon rollout cost 高 / 中间步骤监督浪费 / value target 难构造 / observation target 难构造'推到 'co-evolving acting and forecasting：用一个 forecast head 提供 intermediate supervision / 不依赖手工 value 或 observation target / 提升 sample efficiency'——一个把 'acting policy' 与 'forecast head' 在同一训练循环中共同进化的 agentic RL 框架。'co-evolving acting and forecasting' 把 language agent training 从 'one terminal scalar reward' 或 'hand-crafted value / observation target' 三态拉到 'one-loop co-evolution between policy and forecast'，是 2024-2026 'agentic RL sample efficiency / intermediate supervision / long-horizon agent training' 路线上极具冲击力的具体范式——把 'language agent training' 从 'one-mode trade-off' 拉到 'one-loop mode-fusion'，符合 aiutil 长期关注的 ai-agent × llm-evaluation × inference-serving 主线。

- **新命题 / 新方法 / 新证据：** 提出 co-evolving acting and forecasting = '在同一训练循环中 acting policy 与 forecast head 共同进化 / forecast head 提供 intermediate supervision / 不依赖手工 value 或 observation target / 提升 sample efficiency'。证据来自：跨 long-horizon language agent 任务的 sample efficiency 与 return 实验（待 PDF 核验具体 task 集合与对照基线）。
